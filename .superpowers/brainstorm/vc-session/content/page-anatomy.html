组件清单 · iOS 控制语义化映射

新组件（components/）对应 iOS 语义用途
NeGlassMaterial / Vibrancy玻璃卡片容器：半透明 + backdrop-blur + edge highlight + 新拟态双影（含无 blur 回退）
NeChipFilter Chip场景分类、快捷场景、声音库筛选；选中态用 accent 填充
NeSliderSlider音量、播放进度、混音配比；轨道高亮 + 圆形滑块
NeSwitchSwitch定时关闭、循环、设置项开关
NeSegmentedSegmented Control场景分类 / 发现内容类型切换
NeSheetCard Sheet声音库/定时/播放设置：grabber + 上滑入场 + 下滑关闭 + 遮罩
NavBar / LargeTitleNavigation Bar + Large Title大标题收拢滚动、二级页返回 chevron + 标题
MiniPlayer / PlayerPanelNow Playing悬浮胶囊常驻条 → 上滑展开全屏播放面板
ActionSheet / Alert / ToastAction Sheet / Alert / Toast长按卡片菜单、确认弹窗（uni.showModal/showToast 封装）
EmptyState / ListRowEmpty State / Table Row空数据占位；ios inset 分组列表行（含 chevron）

所有组件由统一设计令牌驱动：背景渐变、glass 材质、双影、圆角、accent、文字三级。`backdrop-filter` 不支持的环境自动回退为更高不透明度纯色玻璃，保证 H5/安卓一致观感。
