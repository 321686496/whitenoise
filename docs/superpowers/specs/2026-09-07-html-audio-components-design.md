# 声栖 · 声音播放组件（单文件 HTML 展示页）设计文档

日期：2026-09-07
状态：已确认（用户已审阅设计方案）

## 1. 背景与目标

声栖是一款白噪音 App（uni-app 原型，仓库见 `prototype/`），已有一套完整视觉体系：
6 套配色方案（莫兰迪/深海/森林/日落/薰衣草/极简黑白）× 3 种 UI 风格（扁平/玻璃拟态/新拟态），
通过 CSS 变量在运行时切换。已有 Vue 组件：SoundCard、SceneCard、MixTrack、PlayBar。

本次目标：**用单个 HTML 文件设计并实现一组声音播放类组件展示页**，满足：

- 延续声栖 App 视觉风格（莫兰迪低饱和、iOS 圆角卡片、磁贴图标质感）

- 全部组件可真实交互：播放/暂停、音量拖动、静音、主题切换、睡眠定时

- 用 Web Audio API 实时合成模拟白噪音（无需音频文件）

- 零依赖、零构建，浏览器双击即可打开

## 2. 交付物

- 单个文件：`d:\app\projects\whitenoise\html\audio-components.html`

- 内嵌全部 CSS / JS / 内联 SVG 图标，无外部资源依赖

## 3. 页面结构（自上而下）

### 3.1 顶栏

- 页面标题："声栖 · 声音播放组件库" + 副标题说明

- 主题切换器：

  - 配色方案：6 个色板圆点（莫兰迪/深海/森林/日落/薰衣草/极简黑白），点击切换

  - UI 风格：3 个分段控件（扁平化/玻璃拟态/新拟态）

  - 当前主题以 `dataset.scheme` / `dataset.ui` 标记在根节点

### 3.2 区块一 · 播放控制

- 圆形渐变主播放按钮：play/pause 图标切换，按下缩放反馈，播放时带扩散波纹动画

- 均衡器动效条：4 柱条形，播放时波浪跳动、暂停静止（灰色）

- 独立音量滑块：轨底 + 渐变填充 + 白色圆形滑块头，支持点击/拖动，显示百分比

### 3.3 区块二 · 声音卡片（6 张）

- 每张卡片：莫兰迪图标磁贴（62px 左右圆角矩形，内嵌 SVG 图标）+ 名称 + 类型 + 选中角标

- 卡片数据取自 `prototype/src/data/sounds.ts` 精选 6 条（白噪音/粉红噪音/雨声/海浪/森林/篝火）

- 交互：点击卡片切换选中并播放/停止对应声音；选中态高亮主色边框 + 柔光阴影 + 勾选角标

### 3.4 区块三 · 场景卡片（2 张）

- 横向卡片：渐变封面（内嵌 2-3 个半透明声音 chip）+ 场景名 + 组合描述 + 播放按钮

- 场景数据：深度睡眠（雨声+白噪音+森林）、自然放松（海浪+森林+溪流）

- 交互：点击播放按钮整组播放（多路合成混音），封面/名称点击无副作用

### 3.5 区块四 · 混音轨道（3 条）

- 每轨：图标磁贴 + 名称 + 音量百分比 + 渐变音量滑块 + 静音按钮 + 移除按钮

- 交互：滑块实时调节该轨音量；静音切灰；移除按钮演示态（点击从视图淡出销毁，可重新选中恢复）

- 真实发声与联动规则：混音轨道至多显示 3 轨，任何播放入口（声音卡片/场景卡）的音频都会汇聚到轨道 1（单音播放）或轨道 1-3（场景组播），轨道名称/图标随之更新；音量调节真实作用于对应音频节点 gain；未使用的轨道显示为空态占位

### 3.6 底栏 · 迷你播放条（固定在视口底部）

- 左：缩略图（渐变圆角小方块）+ 均衡器动效 + 当前场景/声音名 + 定时徽章

- 右：锁定按钮、定时按钮、圆形主播放按钮、收藏按钮（图标按钮按压缩放反馈）

- 锁定态：锁定后背景微高亮，主按钮仍可用

- 点击定时按钮弹出**睡眠定时面板**：

  - 时长选项：15/30/45/60/90 分钟（单选，再点取消）

  - 渐弱时长：1/2/3/5 分钟（单选）

  - 已设定时显示 `mm` 或 `hmm` 徽章；倒计时结束：主音量渐弱至 0，停止播放

- 页面内容区底部预留播放条高度 padding，避免遮挡

## 4. 主题引擎（CSS 变量复刻）

从 `prototype/src/theme/index.ts` 移植 token 表，内联为 `:root` 及每套主题的变量集：

- 每套配色定义：`--app-primary / --app-primary-soft / --app-primary-dark / --app-on-primary / --app-accent / --app-bg / --app-bg-grad / --app-card-* / --app-text / --app-text-2 / --app-text-3 / --app-divider / --app-subtle / --app-danger`

- 每种 UI 风格调整：卡片背景/边框/阴影（新拟态为双阴影浮雕）/是否毛玻璃（backdrop-filter）/输入背景

- 切换逻辑：JS 读取 6×3 组合，将 token 写入 `document.documentElement.style`，并记录 `dataset`

- 默认值：莫兰迪 + 扁平化（与 App 默认一致）

## 5. 声音合成（Web Audio API）

- 统一 AudioContext（用户首次显式操作时 `resume()`）

- **白噪音**：白噪声 buffer + 直通

- **粉红噪音**：白噪声源 + 一阶低通（近似粉红）

- **雨声**：白噪声 + BandPass 带通滤波（中高频带）

- **海浪**：白噪声 + LowPass + 慢速 LFO（0.1Hz 左右）调制 gain，模拟潮汐起伏

- 每个声音拥有独立 GainNode（供混音轨道/卡片音量调节）→ 汇总到 Master Gain（供总音量/渐弱）

- 循环播放：2-6 秒 buffer `loop = true`，单音循环听感连续（噪音/雨声类适合循环）

- 浏览器自动播放策略：首次点击才创建/恢复上下文

## 6. 交互与状态规格

- 播放/暂停：主按钮与卡片点击均切换；播放时均衡器动画、播放条状态同步

- 音量：点击滑块可跳转定位，拖动实时跟随 pointer 事件（pointerdown/move/up）

- 静音：轨道静音按钮切换，状态色切灰

- 定时：选择时长启动倒计时（默认渐弱 2 分钟），到点 Master Gain `linearRampToValueAtTime(0)` 后停止全部；再点同时长=取消

- 收藏/锁定：仅视觉 + toast 提示，无持久化

- 无任何组件处于"未实现"的假状态，所有按钮都有视觉反馈

## 7. 错误处理与边界

- Web Audio API 不可用时（极老浏览器）：按钮仍可切换视觉状态，声音静默降级，页面不报错

- 快速连点播放：以"播放则停其他声音"为原则，避免多路同时播放混乱

- 定时到点渐弱期间提示 toast "定时结束，已停止播放"

- 移除轨道后重建：重新选中对应声音卡片即可恢复

  3. 场景卡整组播放为混音效果
  4. 睡眠定时倒计时结束自动渐弱停止
  5. 窗口缩至移动端宽度布局不破版（卡片自动换行、播放条自适应）
