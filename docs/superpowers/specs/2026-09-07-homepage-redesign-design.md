# 声栖 · 首页重设计（排版 / 布局 / 内容）

日期：2026-09-07
状态：已获用户分节确认（架构 → 模块细节 → 交互/状态/数据流）

## 背景与目标

用户对现有首页的内容、排版、布局、UI 设计均不满意，要求全面重设计。
重设计定位依据：移动端首页承担「流量分发枢纽、价值传递、内容消费场、状态反馈」等角色；
声栖作为**工具型（助眠）**应用，应 **效率优先**：核心功能突出、干扰少、用完即走。

现有首页问题（对应重设计重点）：
- 模块贪多求全：Banner 轮播 + 最近使用 + 声音库 + 混音面板 + 为你推荐，认知负荷过重
- 内容产品化不足：Banner 是运营腔文案，推荐/场景为少量硬编码
- 混音面板占据整块屏幕区域，但首页应聚焦"快速开播"

## 目标架构（方案 A · 即刻助眠流）

页面从上到下，按信息优先级排列，共 7 个层级：

```
① 品牌头部（logo + 声栖 + 问候语；右侧 主题/成就）
② 大播放卡（首屏黄金位：当前场景状态 + 一键播放/暂停；空态兜底引导）
③ 金刚区 2×2 快捷入口（开始助眠 / 专注时刻 / 自然放松 / 每日签到）
④ 今日精选（横滑 2 张大卡，替代原 3 张自动轮播 Banner）
⑤ 场景推荐（分类 Tab + 两列竖向卡片网格）★内容主体
⑥ 最近使用（横滑小图标，无记录时整块隐藏）
⑦ 声音库入口条 + 底部 PlayBar / TabBar
```

关键变化：
- 混音面板移出首页主流程：大播放卡承接播放态，音轨调节收纳进 PlayBar 展开面板
- 3 张运营轮播 Banner 改为 2 张产品化精选卡（非自动轮播）
- 12 个声音不再平铺，改为声音库入口条

## 模块视觉与内容

### ① 品牌头部
- 左：logo（84rpx 圆角方片）+「声栖」46rpx 粗体 + 一行时间问候副文案（按时段变化）
- 右：主题（调色盘）+ 成就（奖杯）按钮
- 头部总高控制在 110rpx 内，间距收紧

### ② 大播放卡（核心）
- 全宽卡，32rpx 圆角，背景 `linear-gradient(135deg, primary → primaryDark)`，白字
- 状态 A（播放中/有混音）：左上场景名 + 音轨数标签（如 `3/6 路`）；中央 4 条播放波线（CSS 动画作播放反馈）；右侧 96rpx 圆形播放/暂停主按钮（白底主色图标）；底部一行「定时 / 保存场景」白字小操作
- 状态 B（未播放空态）：moon 图标 + 「开始你的助眠之旅」+「点选下方场景，即刻开播」；点击播放按钮 toast「请先选择场景」
- 波线动画仅作播放状态反馈，克制，不做图片动效

### ③ 金刚区（2×2 卡片网格）
- `.app-card` 风格，两列两行；每项 = 图标磁贴（80rpx 圆角方片主色柔底）+ 名称 + 一行小描述
- 入口：开始助眠（moon，一键深度睡眠）/ 专注时刻（flame，纯净白噪）/ 自然放松（forest，跳场景页自然分类）/ 每日签到（gift，跳签到页）

### ④ 今日精选（横滑 2 张大卡）
- 去掉自动轮播；静态横滑 2 张
- 每张：场景专属渐变 + 左上标签「今日精选」+ 情感化主文案 + 右侧场景图标与播放按钮；点击整卡应用并播放
- 内容：「雨夜入眠」（雨声 × 白噪音，一夜好眠）、「专注结界」（白噪 × 粉噪，快速进入心流）

### ⑤ 场景推荐（分类 Tab + 两列网格）★内容主体
- Tab：全部 / 助眠 / 专注 / 放松 / 自然
- 两列竖向卡片：顶部渐变封面（高约 150rpx，场景图标居中）+ 底部信息区（场景名、声音组成、播放小按钮）；播放中卡片显示波线状态
- 场景数据（10 个，替换原 4 个硬编码推荐）：

| 分类 | 场景 |
|---|---|
| 助眠 | 深度睡眠（雨+白噪+森林）、夜雨入眠（雨+风扇）、海浪催眠（海浪+白噪） |
| 专注 | 专注白噪（白噪+粉噪）、咖啡厅午后（咖啡+风扇）、长途列车（列车+白噪） |
| 放松 | 自然放松（海+林+溪+火）、森林冥想（森林+溪流）、篝火夜晚（篝火+虫鸣） |
| 自然 | 林间溪流（溪流+森林）、山野清晨（森林+鸟鸣） |

### ⑥ 最近使用
- 保留横滑形式，压缩尺寸（80rpx 图标 + 名称 + 时间），置于场景网格下方；无记录整块隐藏

### ⑦ 声音库入口条
- 单行入口卡：声音图标 + 「声音库」+ 副文「12 种白噪音，自由混音」+ 右箭头，点击跳声音库页

### 底部
- PlayBar：展开面板收纳原混音音轨调节（MixTrack 列表）；TabBar 不变

## 交互与状态

| 元素 | 交互 |
|---|---|
| ②大播放卡 | 播放按钮：有混音→播/暂停；无→toast。点场景名区域→底部弹出混音面板。定时/保存→现有弹窗 |
| ③金刚区 | 开始助眠→应用「深度睡眠」播放；专注时刻→应用「专注白噪」；自然放松→场景页并定位「自然」；签到→签到页 |
| ④今日精选 | 点击整卡→应用场景并播放 |
| ⑤场景网格 | 未播：点击→应用并播放；播放中同一场景：暂停/继续；播放中不同场景：切换。图标态：未播=播放图标 / 播放中=波线 |
| ⑥最近使用 | 点击→恢复播放 |
| ⑦声音库 | 点击→跳转声音库页 |

### 状态管理
- 新增共享播放状态 `src/composables/usePlayer.ts`：`currentScene`、`activeTracks[]`、`isPlaying`、音量/静音、定时器；大播放卡、场景网格、PlayBar 读写同一状态
- 场景数据结构统一：`{ id, name, category, sounds[], iconName, bgColor, isPreset }`，首页与场景页共用

### 数据流
- 场景数据抽到 `src/data/scenes.ts`（11 个场景含分类），首页网格与场景页共用
- 最近使用：`uni.setStorageSync` 本地读写，播放时写入，去重、上限 10 条，首页取前 3
- 今日精选 / 金刚区：本地常量配置
- 金刚区「自然放松」：通过 `uni.switchTab` + 全局状态（`usePlayer` 中记录目标分类）定位场景页 Tab；场景页 `onShow` 时读取并切换

### 空态兜底
- 大播放卡：未播放引导文案
- 最近使用：无记录整块隐藏
- 场景分类：无数据时显示「暂无此类场景」占位（数据已保证每类 ≥2）
