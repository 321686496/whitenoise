# 白噪音 App 设计文档

日期：2026-08-17
状态：已确认

## 概述

一款跨平台白噪音 App，支持多声音混合调音、定时器、后台播放、收藏与历史，并支持多种 UI 风格与配色切换。采用 Flutter 一套代码输出 Android / iOS / HarmonyOS，优先开发 iOS 与鸿蒙。

## 目标平台与优先级

- 首选：iOS、HarmonyOS
- 兼容：Android
- 技术栈：Flutter，一套代码多端

## 功能范围

1. 声音库与切换：首发程序合成噪音（白/粉/褐/棕），预留真实录音接入点
2. 多声音混合调音：多路声音同时播放，每条独立音量调节
3. 定时器：倒计时 / 到点自动停止（淡出停止）
4. 后台播放：锁屏/切后台继续播放
5. 收藏与历史：本地持久化，记住当前声音组合与音量设定并自动恢复

## 架构

分层单体、一套代码多端：

```
┌─────────────────────────────────────────────────┐
│  UI 层（Flutter Widgets）                        │
│  声音库/混音面板/定时器/收藏/设置                 │
├─────────────────────────────────────────────────┤
│  主题层（AppTheme）：3 种 UI 风格 × N 种配色       │
├─────────────────────────────────────────────────┤
│  音频引擎（Dart 统一混音器）                      │
│  单路 PCM 流 → just_audio StreamAudioSource        │
├─────────────────────────────────────────────────┤
│  平台层：iOS(音频会话/后台) · OHOS · Android     │
└─────────────────────────────────────────────────┘
```

### 统一 Dart 混音引擎（已确认：方案 A）

- 每条音轨 = 一个 `TrackGenerators`（噪音生成器 / 已解码 PCM 循环）
- `Mixer` 按各轨音量加权求和、防削波，输出单路 PCM
- 经 `StreamedAudioSource` 交给 `just_audio` 播放
- 每条轨支持淡入淡出，切换/停止时避免爆音
- 定时器通过引擎掌控停止时机实现到点自动停

### 主题系统（已确认：风格化装饰器 + 共享数据层）

- 数据层持有同一套"声音集 / 配色 token / 功能状态"，与视觉风格解耦
- 每种 UI 风格提供一组装饰器 Widget（卡片、滑杆、按钮、背景容器），从 `AppTheme` 读取风格与配色参数
- 支持的风格：新拟态、玻璃拟态、扁平化；配色可多套切换（含莫兰迪配色）
- 切换风格/配色即时生效并持久化

## 数据流

- 声音素材杂交到资源层，不阻塞 UI
- 用户的声音组合、各轨音量、偏好风格/配色、收藏历史均本地持久化
- App 启动时自动恢复上次的组合设定

## 平台与后台播放配置

- iOS：配置 AVAudioSession（`mixWithOthers` / `playback`），Info.plist 声明后台 `audio` 模式
- HarmonyOS：选用多媒体输出并启用后台播放
- Android：使用前台服务保活后台播放
- 音频插件：`just_audio`（含 OHOS 支持）+ 音频会话配置

## 错误处理

- 音频会话启动失败、资源解码失败：统一降级（静音回退）并提示用户
- 所有降级路径不影响 UI 可用性
